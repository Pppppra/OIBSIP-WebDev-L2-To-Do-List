
#  Description

A simple and interactive To-Do List Web App built using HTML5, CSS3, and Vanilla JavaScript. It allows users to add, edit, delete, and complete tasks with data saved using localStorage.

### Features

* Add new tasks
* Mark tasks as complete
* Edit existing tasks
* Delete tasks
* Separate Pending and Completed lists
* Display task counts
* Show task timestamps
* Save tasks using localStorage
* Responsive design
* Empty-state messages
